# Media3 FFmpeg decoder

`lib-decoder-ffmpeg-release.aar` is the Media3 FFmpeg extension used by the
upstream Ghosten Player v2.4.7 release build. It enables codecs such as TrueHD
that are unavailable through the projector's platform decoders.

- Upstream workflow run: https://github.com/GhostenEditor/Ghosten-Player/actions/runs/35632745118
- Artifact name: `media3-extension`
- AAR SHA-256: `132464e421e0929c9f4e461ba1489554c081cebcd01677a2c4c74c545225c699`
- `armeabi-v7a/libffmpegJNI.so` SHA-256: `f5b669db265a4e68a5db193b006d90c2aaddbbf5be49a427c47171b0c7ba2264`

The native library hash matches the one packaged in the official v2.4.7 TV
APK.
